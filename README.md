# 🌦️ Weather App

A simple, clean weather application that lets users search for real-time weather information by city name.

## 📋 Description

This project is a basic front-end Weather App where users can enter a city name and get weather details instantly. Built using core web technologies — HTML, CSS, and JavaScript.

## ✨ Features

- 🔍 Search weather by city name
- 📱 Responsive and simple UI
- ⚡ Fast and lightweight

## 🛠️ Tech Stack

- **HTML** – Structure of the app
- **CSS** – Styling (`weather.css`)
- **JavaScript** – Logic and API handling (`weather.js`)

## 📂 Project Structure

```
weather-app/
│
├── index.html      # Main HTML file
├── weather.css      # Stylesheet
├── weather.js        # JavaScript logic
└── README.md         # Project documentation
```

## 🚀 How to Use

1. Clone or download this repository
2. Open `weather.html` in your browser
3. Enter a city name in the input box
4. Click the **Search** button to view the weather details
